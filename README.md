# prueba

Los tres estados de Git y sus comandos clave.

## 1. Directorio de Trabajo
Archivos sin seguimiento o modificados.
```
git init
git status
```

## 2. Area de Preparacion
Cambios listos para el proximo commit.
```
git add archivo
git status
```

## 3. Repositorio Local
Historial de commits confirmados.
```
git commit -m "mensaje"
git log
```

## 4. Repositorio Remoto
Copia del repositorio en GitHub.
```
git remote add origin <url>
git push -u origin main
```
